### divergence

- **open-does-not-run-initial-state** (formula/journey-01-approval-loop step 1) [related: v0.3 PRD §6.5 / design doc L2-5]
  openInstance 只把实例写在初始状态并标记 waiting，不执行初始状态；实例必须等第一条消息（Restore）才前进——『开通 + Restore』约定（design doc v0.2 §10.4 [L2-5]）是当前唯一可用形态。
- **open-not-idempotent** (formula/journey-01-approval-loop step 3) [related: v0.3 PRD §6.5 / design doc L2-5]
  openInstance 非幂等：重复 ensure/open 抛 duplicate workflow instance 而不是返回既有快照，项目被迫实现先查后开的竞态协议（v0.3 §6.5 要求幂等 provisioning；验收标准 7）。
- **G3-local-tool-via-remote-workaround** (formula/journey-02-generation-loop-and-divergences step 13) [related: v0.3 PRD §6.1 / 分析文档 G3]
  写本地业务库的 startGeneration/recordArtifact/approveDesign 只能声明为 remote-http-json@1 并由进程内 transport 伪装承接（G3/PRD-CR-1 临时方案 A）：createRuntimeToolExecutor 对 script/remote 之外的 execution kind 一律抛 Unsupported Tool binding kind，registered/local 绑定无一等公民。
- **L2-4-idempotency-key-not-transported** (formula/journey-02-generation-loop-and-divergences step 14) [related: design doc v0.2 §9.4 [L2-4]]
  冻结的 RemoteTransportRequest 只携带 {binding, input, resourceKey, signal}：EffectExecutionContext.idempotencyKey 停在 journal 层，永远到不了执行端——写业务 Tool 的幂等只能靠 payload 里的 commandId 约定（design doc v0.2 §9.4 [L2-4]）。
- **137-inapplicable-message-poisons-instance** (formula/journey-02-generation-loop-and-divergences step 33) [related: issue #137 / PRD-CR-2 / v0.3 PRD §6.3-6.4]
  复现 #137：契约合法但在当前状态不适用的消息（Restore 之前到达的 JobFinished，即 provisioning 竞态窗口）→ 处理抛错 → disposition=failed → 实例 recovery_required → 整个 mailbox 被阻塞。长寿命实例会因一次时序竞态被冻结直到人工恢复；v0.3 §6.3–6.4 要求一等 rejected(not_applicable) 处置。W3 全事件覆盖约定只能缓解、不能消除该窗口（init 状态按 W4 只接受 Restore）。
- **137-retry-cannot-resolve-inapplicable-message** (formula/journey-02-generation-loop-and-divergences step 38) [related: issue #137]
  对『不适用消息』型毒化，recovery retry 只会重放同一条消息并再次失败（recovery_required → retry → recovery_required）；唯一出路是 resolve/terminate 放弃该消息。这证明 rejected 处置必须在平台层解决，恢复原语无法替代。
- **G1-domain-data-key-unchecked-at-compile-time** (formula/journey-02-generation-loop-and-divergences step 41) [related: 分析文档 G1 / v0.3 PRD §6.7]

- **G2-business-source-has-no-package-declaration** (formula/journey-02-generation-loop-and-divergences step 43) [related: design doc v0.2 §11.4 [L2-8] / 分析文档 G2]
