# Private DIS Runtime Consumer

This workspace is a private `0.11.0-dev.0` Runtime Consumer for the bounded read-only xDownload Domain App. Its Boot entry checks the emitted KDP Primary bytes and invokes their fixed entry. KDP creates the selected Kernel Core over physical SQLite CAS before building or attaching an application.

The Kernel ABI requires interpreter and policy endpoints at construction. KDP supplies its internal read envelope and a fixed read transport policy. These establish the occurrence, state, admission and Journal boundary and contain no player semantics. The Kernel's original receipt attributes those endpoints by their internal identities. The attached Standard Router checks the sealed BUILD route. The attached Business Package declares the selected Definition and Graph, and the attached capability evaluates the graph using the locked provider bytes and versioned Knowledge.

The Package System verifies one BUILD snapshot and binds its exact read operation once. The provider runs inside the K-owned occurrence. It has no storage or external effect port. KDP retains admission, state, CAS, Journal and replay authority. Readback derives the Journal address from the selected Kernel's key builder and the original receipt's effect ID.

This lane covers the private reference qualification only. See the [example](../../examples/dis-0.1.0-runtime-consumer/README.md) and [R1 evidence](../../validation/dis-0.1.0/RUNTIME_REPAIR_R1.md).
