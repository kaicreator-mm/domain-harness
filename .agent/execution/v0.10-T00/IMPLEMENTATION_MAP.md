### `.../v10build/import-policy.ts`
- `collectModuleEdges(label, source)` — pinned-parser (vendored acorn via
  `../v09build/generated/acorn.mjs`, pin asserted through
  `assertVendoredParserBytes`) ONE-PASS static collection of: static imports,
  export-from, literal dynamic import(), computed dynamic import(), require,
  eval/Function-family code strings.
- `assertSealedImportClosure(label, source, policy)` — v0.10 semantics
  (successor of v09 `import-closure.ts`, which stays frozen for v0.9):
  `node:*` and bare npm/native specifiers allowed IFF declared in the
  module's sealed `externalImports`; computed dynamic import, require, eval /
  Function constructors, relative/absolute/`data:` edges and cross-packageId
  imports refused typed (`V10_IMPORT_POLICY_DENIED`). `import.meta` access is
  ordinary ESM and allowed (it is not a module-graph edge); the gate reasons
  only about module edges and code-string evaluation, never about
  business semantics.

### `.../v10build/build.ts`
- `buildV10App(options)` per EXECUTION_CONTRACT §1.1: snapshot → strict
  fields → target/profile/ABI table → closed-role cardinality → advisory
  provider/hook + feature-key + intent uniqueness → authority-namespace
  reservation → dependency completeness → acyclic deterministic load order
  (role rank + DFS, sealed into output) → required-feature completeness →
  optional-skip bookkeeping → per-module byte pin + sealed import closure
  (once-only static preflight; zero evaluation) → route admission against
  sealed intents/capability handlers → canonical digest → frozen plain-data
  `V10BuiltApp` (no approval field at all).

### `.../v10build/activation.ts`
- `activateV10App(app, { store, tenantId?, now?, counters? })`: structural
  plain-data check (NO re-hash/AST/dependency recompute) → private
  per-activation `data:` URL import in SEALED load order → per-role
  structural connect (kernel `createOccurrenceRuntime`, standard
  `interpret`+`routeWorkflowIntent`, business `getPolicy`, capability sealed
  handlers, advisory sealed surfaces) → bounded data-only port-denying init
  context (PROTECTED port names denied; probe recorded) for S features then
  K extensions in sealed order; init contract check (plain record, exact
  fields, identity confirm); ANY late failure disposes ONLY initialized
  advisory modules in reverse and closes the facade → `V10AppFacade`:
  `send(intent)` = sealed-route Router selection (real v0.9 workflow-router
  semantics via the sealed standard module) → one `createOccurrenceRuntime`
  per business package (docs port over caller store with CAS condition
  mapping, sdkEndpoint.interpret, businessEndpoint=policy, observe) →
  `openInstance` (idempotent on CAS conflict) → `submitOccurrence` receipt;
  `kCounters(businessId)`; `selectedExtensions`/`selectedFeatures`;
  `close()`; `activation.dispose()` (facade close + reverse advisory
  disposal). Advisory turn-time consultation semantics are NOT implemented
  here (research/K-side scope — see EXECUTION_CONTRACT §3).
