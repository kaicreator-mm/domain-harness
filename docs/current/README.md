# 文档语言入口 / Documentation languages

- **面向用户，默认中文：[中文手册](zh-CN/index.md)**
- **面向 Coding Agent，默认 English：[English Agent/developer docs](en/index.md)**

两套当前文档按相同主题名一一配对，互相跳转。历史研发证据请从各自语言的 `archive.md` 进入。

**规则 / Policy:** edits to a current topic must change the matching `zh-CN/<topic>.md` and `en/<topic>.md` together. Generated prompts and machine-facing `AGENTS.md`, `llms.txt` and the canonical `SKILL.md` remain in English for Agent parsers; their human usage is described in both languages. Frozen historical records remain unchanged.
