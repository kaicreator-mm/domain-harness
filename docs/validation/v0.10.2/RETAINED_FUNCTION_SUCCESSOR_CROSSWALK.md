Vocabulary. **Class** uses the original crosswalk set only (`SEMANTIC`, `TOOL_READ`, `TOOL_EFFECT`, `KERNEL_PROTOCOL`, `BUILD_OR_LIFECYCLE`) plus `PRIVATE_NON_TOOL` for code that stays inside its owner (PRD PD-01); the #1304 readability planes are aliases, not a taxonomy. **The five reachability columns are kept separate** (#1310): *present* = the code exists on the selected path in source; *packaged* = it is in an `npm pack --dry-run` packlist today (INV §4: the compiler packlist carries `dist` plus the payload `.mjs` files, the core packlist carries `dist` with host-v8; physical install is NOT_RUN); *selected* = a BUILD composition includes it (Tiny = K/S/B/C, 4 modules; Rich adds features, advisories, extra B/C); *reachable* = the public route through which a consumer can trigger it today; *validated* = the test status at the pin. `FACADE_TODAY` = `V10AppFacade` method; `HOST_INVOKED` features are called through `invokeSelectedStandardFeature` and are **not** bound into a K turn (#1267 stays OPEN, L2 §11).

**Action** values: `MIGRATE` = the selected implementation moves with its owner task, behaviour-preserving; `KEEP` = nothing moves (external, legacy-only, or decided NOT_REQUIRED); `PRODUCT_DECISION` = an inherited Product decision is open **and** no selected implementation exists to move; `NEW` = bounded new code authorized by a Product decision (only HF17, PD-02); `REMOVE` and `DEFER` are unused (no invented deferral). **Disposition** tokens: `SELECTED_MOVE_PRESERVE` (selected behaviour moves as is; the unproven historic remainder is carried forward, not reimplemented), `PRODUCT_DECISION_INHERITED` (the closure ledger §4 question is still open; v0.10.2 neither implements nor excludes it), `NOT_REQUIRED_FROZEN_CLAUSE`, `NOT_REQUIRED_FOR_V0102`, `OUT_OF_SCOPE_V0102`, `REBOUND_SELECTED_K`. **Triage (non-binding)** is the R1 amendment's (a)/(b)/(c) split as far as evidence allows: `WITNESS_GAP` = selected semantics exist and a named P/N property is unproven; `NO_SELECTED_OWNER` = the historic subject has no selected successor. No (b) "superseded" triage is asserted for a PARTIAL row because no quoted Product disposition exists at the pin; closing any PARTIAL row is a Product/owner act, not a T08a act.
