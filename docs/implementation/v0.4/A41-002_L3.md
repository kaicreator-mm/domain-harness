## 2. Objective (concern boundary)

Implement the bounded **consumer/verifier, never issuer** for DAC v0.0.4.1
F-01 designation/delegation/currentness and F-06 AuthorityAdoption
semantics:

1. `verifyDacV0041DesignationChain` — deterministic designation-chain
   verification over externally recovered facts: §2 who-may-issue (scope
   owner or chain-current `designation-issuance` holder; no other role
   implies designation power; Composer never), §3 delegation envelopes,
   §4 directed attenuation/non-escalation, §5 re-delegation depth, §6 chain
   recovery, §7 prospective ends, §8 retroactive void with cascade, §9
   SoD/co-location interaction — with the frozen pass order
   structural → authority → void → lapse documented on the result type;
2. `verifyDacV0041AuthorityAdoption` — F-06 §6 consumer verification with
   the frozen precedence ladder: facts → non-adoptable class → class
   precondition → exact historic-source binding (foundation-minted
   reference + role/class coherence + exact frozen `predecessorOrigin` +
   claimed origin profile exactly equal to the artifact's closed
   `contractProfileIdentity`) → complete re-evaluation → issuer chain at
   the adoption point → exact issuer/role/scope → constraint/profile/SoD
   coverage → independent adoption evidence → no backdated effect →
   `ADOPTED_PROSPECTIVE` (authority effective only from the adoption
   point);
3. `classifyDacV0041HistoricAuthorityArtifactUse` — F-06 §6.1 direct-use
   gate: a historic artifact without v0.0.4.1-valid issuance-time
   designation evidence is `ADOPTION_REQUIRED` (C145); a v0.0.4 artifact
   whose chain already satisfies v0.0.4.1 needs no adoption; successor-native
   artifacts are not this classifier's gate.

Explicit non-goals (authority ceiling): no root AuthorityDesignation
issuance, no upstream authority establishment, no promotion/selection/
Manifest issuance, no independent conformance verdict issuance, no
compatibility evaluation (A41-003), no composition-intake/selection/Manifest
verification (A41-004), no Runtime binding/activation behavior (41-005),
no COMPATIBLE/INCOMPATIBLE disposition, no central public export wiring.
Every function is pure and total: malformed/hostile inputs are returned as
typed FAIL_CLOSED results (never thrown, never guessed, never repaired).
