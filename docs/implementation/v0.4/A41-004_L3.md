## 2. Objective (concern boundary)

Implement the bounded **consumer/verifier, never issuer** for externally
owned DAC v0.0.4.1 F-04 composition-intake evidence:

1. `verifyDacV0041CompositionIntake` — deterministic intake verification of
   one complete externally recovered evidence bundle: exact
   `ApplicationIdentityEstablishmentRef` facts (F-04 §4.1 minima; C141
   anti-alias; initiation minimum), `ApplicationSelectionRef` facts (C140:
   establishment issuance strictly precedes selection issuance;
   APPLICATION_MANIFEST §2: selection precedes Manifest issuance),
   successor Manifest evidence facts (C88 identity separation across
   Manifest/digest/revision/semantic identity; no ManifestDraft in a result
   position), total selected Domain Data coverage (C80/C81: effective
   promotion + selection coverage for EVERY selected subject wherever
   Runtime consequence depends on it, with currentness states), and
   seam-typed material `AuthorityRefusalRef` evidence (C142/C143);
2. `verifyDacV0041AuthorityRefusalEvidence` — standalone F-04 §4.2 refusal
   intake: closed seam vocabulary (designation issuance / identity
   establishment / Manifest issuance / Runtime binding / Runtime
   activation), refusal != invocation failure (`produced-result` only),
   binding != activation seam conflation, request/refusal identity
   distinctness, refusing-issuer designation;
3. Frozen result precedence ladders documented on both result types
   (structural → carrier → role → predecessor-wrap → alias → evidence →
   authority → ordering → exact matching → coverage totals/currentness →
   refusal semantics), mirroring the structural-dominates-staleness rule
   of C152/C171.

Explicit non-goals (authority ceiling): no application-identity
establishment issuance, no ApplicationSelection authority, no
AuthorityRefusal issuance, no promotion, no Manifest issuance or drafting,
no Composer role, no compatibility evaluation (A41-003, untouched
compatibility module), no Runtime binding/activation (A41-005), no

Manifest-into-runtime-state collapse), no central public export wiring, no
`dac-v003*` changes, no A41-003 lane files. Every function is pure and
total: malformed/hostile inputs are returned as typed FAIL_CLOSED results
(never thrown, never guessed, never repaired).
