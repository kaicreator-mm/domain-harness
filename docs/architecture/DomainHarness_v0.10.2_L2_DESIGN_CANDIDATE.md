### 1.2 Import-direction DAG (arrow = "may import"; this is the L2-C answer)

```
 tooling/build ----------------------------> packages/contracts <---------------------- packages/microkernel
 (BUILD only; no microkernel/host import)         ^   ^                                         ^
                                                  |   |                                         |
 packages/host-node ------------------------------+   +----- (types, constants, errors) ---------+
        |  ^                                                    host-node -> microkernel only via "./host-seam"
        |  +-- optional peer: better-sqlite3 (dynamic import, sqlite-cas-store.ts:208)
        +----------------------------------------------------------------------> packages/microkernel

 domain-packages/**  and  examples/**/modules/** : sealed ESM, ZERO workspace imports
        (BUILD refuses cross-package edges, build.ts:31-34,47-49; only node:* and declared npm/native allowances)
 Legacy (packages/domain-harness, -compiler, -node, -expo): may import ANY new package (forwarding shims);
        NO new package may import a legacy package.
 Tests / examples / extensions: may import anything.
```
Forbidden edges (enforced, section 1.4): `contracts -> *`; `microkernel -> host-node | build | legacy | domain-packages`; `build -> microkernel | host-node | legacy`; `host-node -> build | legacy`; `domain-packages -> any workspace package`.
